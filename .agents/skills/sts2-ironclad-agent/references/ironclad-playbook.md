# 铁甲战士实战手册

**兼容目标：** Steam Main `v0.107.1`；**资料核对：** 2026-09-24。
**事实优先级：** 当前游戏 MCP 快照 / 已安装 `release_info.json` → 本机分支游戏数据 → 标注版本的攻略 → 社区观点。牌值、费用、意图、目标和行动是否合法，永远以当前游戏状态为准。

## 核心原则

低难度铁甲战士应把有效前置伤害作为整局的构筑与节奏方向：更快结束普通战斗本身能少承受后续回合。但这不等于每回合先出攻击牌，也不等于余血看起来充足就默认接受掉血。完整线路要一起衡量敌方实际 HP 损失、格挡实际避免的玩家 HP 损失、击杀取消的攻击、自损和能量机会成本。攻击只有在当前威胁较轻，或它能明显推进击杀/结束战斗，而且没有放弃更有价值的防守时才有节奏理由；格挡能避免显著掉血而攻击只推进少量伤害、不能击杀或改变当前威胁时，应认真选择防守。被敌人格挡完全吸收、没有同回合转换或已确认副效果的攻击没有进度。纯力量或易伤设置牌也要有本回合实测到的 HP 伤害增量，不能只因“加了属性”就打。格挡没有实际减伤或后续用途时，也不要为了“正在被攻击”就硬叠。

当前安装版本的对局记录显示，损失少量 HP 换取真实伤害/节奏有时合理，但在低 HP、来袭伤害高或有更好防守线时，同样的交易可能致命。燃烧之血只在战斗结束后回血，不能挡本回合伤害，也不能把致死自损变成安全动作。

## 每次战斗决策

1. **先核对状态。** 读取玩家 HP、格挡、能量、手牌和牌堆，逐个查看敌人 HP、格挡、状态和意图。目标、费用或意图缺失时，当前估算不完整；不要假装确定。
2. **比较同一回合的完整线路。** 对每个合法首动作，用共同的能量预算列出可支持的后续出牌。一个线路至少记录：逐击通过敌人格挡后打到敌方 HP 的伤害、击杀取消的本回合攻击、自损、格挡后本回合会损失的 HP，以及动作顺序。固定伤害、多段、全体和 X 费攻击只有在牌面公式和目标被识别时才纳入精确计算；X 费命中次数取打出时剩余能量，多段 Strength 按每击计算，全体伤害逐个敌人结算。分开的线路是互斥方案，不能把最佳伤害线的攻击和最佳生存线的格挡拼成一条。
3. **先排除致死线，再比较本回合交换。** 把不同首牌开始的完整线路放在同一个 Pareto 前沿；只删除在实际敌方 HP 伤害和我方未封顶 HP 损失上都不优、且至少一个维度更差的精确线路。若另有精确存活线，删除确定致死线；如果所有精确线都致死，先保留本回合未封顶掉血最低的线路。低进阶的“偏攻”是整局构筑和战斗节奏方向，不给本回合攻击动作默认优先级。逐线比较实际 HP 伤害、格挡避免的 HP 损失、击杀取消的威胁、敌方余血和能量机会成本；usable 只代表未触发同等当前威胁压力标记，不代表应攻击。防守能避免显著掉血而攻击只推进少量伤害时，应认真选择防守；威胁较轻且攻击能明显推进或结束战斗时，再考虑用伤害换节奏。伤害和掉血没有通用的 1:1 汇率，不给攻击牌型本身加分。未建模药水/卡牌仍各自作为未知分支，不会污染其它已精确线路。
4. **攻击看结果。** 扣到敌方 HP 或确实击杀有攻击意图的敌人，才算相应收益。非致命攻击不会取消意图；只削敌人格挡不是伤害。只有同一条可支持线路里的后续牌确实打到 HP，才把清格挡当成这条线路的铺垫。不能因为手里有一张“能打”的后续牌就保留清格挡动作：若合并能量与结算顺序后的最好线路仍打不到敌方 HP，就删掉这个已证明无转换的攻击。未知药水仍保留为独立选项，先用药水并重读状态后再重算。
5. **防守看挡回的 HP。** 先算现有格挡之后敌人会造成多少伤害，再看这张牌或击杀能减少多少。若新增格挡被现有格挡覆盖或敌人当前不攻击，就不能把格挡数当成收益；若格挡能避免实际掉血，就必须计入线路比较。敌人攻击造成的 HP 损失与卡牌自身失去的 HP 分开记录：格挡不能抵消御血术、放血等自损。没有敌方来袭时，别用无收益的格挡去“抵消”卡牌自损；应判断自损牌本身值不值得打。
6. **力量/易伤设置必须在本回合兑现。** 按“设置费用 + 本回合全部可执行攻击”的完整线路核算；没有增加敌方HP伤害或其它已确认的本回合效果，就不花能量设置。力量逐击加伤，攻击先过每个目标现有格挡。Main v0.107.1 的 **预备打击（Setup Strike）** 先造成 7 点伤害，再获得 2 点本回合力量，只有后续攻击能用到它；如果完整线路仍只削格挡，就没有当前伤害收益。纯易伤牌（例如 **战栗 / Tremble**）只影响选中的目标；没有能量打出同回合攻击、目标已有易伤而伤害不再增加、或敌人格挡吸收全部伤害时，不计为当前兑现。若目标有 Artifact，易伤不能按已生效计算。全体与 X 费攻击按打出时剩余能量和每个目标分别估算。**燃烧（Inflame）**提供永久力量；**恶魔形态（Demon Form）**在后续回合开始时加力量，不能被当前回合攻击公式提前使用。如果纯力量/易伤设置本回合整条可执行线路没有增加HP伤害或确认副作用，就从本轮候选中移除。牌堆里的攻击不能替代当前兑现证据，因为现在无法保证抽到顺序、费用、敌人存活时间或是否能穿过格挡。已在手牌的攻击能兑现即时设置时，再比较它与攻击、格挡的完整线路及能量机会成本；任何牌不因类型或牌面数值自动加分，也不为清手牌或花能量而出。
7. **攻防看实际效果。** 击杀的防御价值是它实际取消的本回合来袭伤害；非致死伤害不会取消当前意图。格挡只按确实减少的本回合 HP 损失衡量，过量格挡不加分，除非有已建模的保留/转化。A0-A2 的偏攻是整局构筑和战斗节奏方向，不是每回合攻击默认。打不掉敌方 HP、不击杀、不触发已建模效果的攻击，不得仅因是攻击牌被偏好；usable余量不代表应攻击。若格挡能实质减少HP损失而攻击只推进少量伤害，应认真比较防守线；若当前威胁轻、伤害能显著推进或结束战斗，再考虑用伤害换节奏。`critical` 是同等可见威胁下的生存压力提示：若非致死攻击线会把余血压到当前剩余来袭伤害以内，而防守线能明显改善余量，就把防守作为优先候选；只有攻击能结束战斗或实质取消更多当前威胁时，才优先牺牲这段防守。真实攻防取舍交给 KEV 结合余血、来袭、敌方剩余 HP 和整条线路判断。
8. **允许结束回合。** 若剩下动作只有零 HP 输出、无兑现的设置、过量伤害或会浪费防守资源，可以结束回合。若有可支付的格挡牌能净减少本回合来袭伤害，不要仅为保留能量而结束；先打这一张，再重读状态、重新决策。致死压力下，即便一张格挡不足以单独存活，也可先打出能净减伤且带抽牌等效果的牌，再检查新状态和剩余动作。X 费攻击在 0 能量时是 0 次命中；即使敌人带有易伤等伤害倍率，也不能把 0 次攻击估成有收益。全局比较后只剩一个有意义的首动作时直接执行；仍有真实攻防交换时 KEV 才在当前合法集合里选。攻击必须有实际敌方 HP 伤害、击杀或受支持的同回合转换；单纯打掉敌人格挡不算进度。若伤害修正或牌面效果未解析，不得把估算为 0 当成已证明的 0。
9. **KEV 选完整线路，控制器逐步验证。** KEV 对可比较局势选择一条完整的本回合线路，不只挑第一张牌。控制器每提交一步都立即重读 MCP 状态，用当前手牌/药水身份重新绑定下一步并检查合法性；不能只因牌索引变化就丢弃整条线。下一步已不合法、实际状态偏离支持条件，或线路标记到不确定效果时，才丢弃剩余步骤，并用新状态再问 KEV。线路已经选过不代表可以绕过实时合法性校验。

### 需要优先处理的局势

- **确定击杀：** 计入这名敌人本回合实际被取消的攻击。多敌时，其他攻击仍要保留在来袭总量里。斩杀是高价值选项，不是忽略更安全线路的口令。
- **低 HP 或致死压力：** 已知自损会导致 HP 归零时，不打该牌。若一条完整、受支持的线路能存活而另一条确定死亡，选择存活线路；不要用不完整估算覆盖 KEV 的选择。
- **可挡且可攻击：** 让 KEV 在同一轮的完整线路之间比较敌方 HP 伤害、实际挡回的 HP 和击杀取消的来袭攻击，不靠固定偏置替玩家决定。若一条线路先清敌人格挡、靠后续攻击造成伤害，选中后控制器会继续执行那条受支持的后续线路；不能清完格挡后重新分类时又空过。
- **敌人不攻击：** 纯格挡没有本回合减伤价值，除非存在可见的格挡保留或转伤害机制；有效攻击或可兑现设置仍按当前线路评价。
- **多个攻击者：** 逐个计算谁被击杀、谁仍会攻击，再比较总的剩余 HP 损失；不能把击杀一个小怪当成挡住全部来袭。
- **力量与能力牌：** 先比较打出后的完整线路收益和能量机会成本。纯力量牌若本回合没有HP伤害增量或其它已确认即时效果，不交给 KEV 猜未来回报，也不因牌堆里有攻击就放行。已在手牌中的攻击能兑现力量时，才把设置线与不设置线作为同回合候选比较。未建模的多回合 Power 保持未知；任何牌型都不能自动获得优先级。

## 选牌与构筑

铁甲战士没有必须强行凑出的单一路线。牌组应该补当前缺口：早期通常需要可靠的单体伤害/AoE；随后看是否有力量兑现、多段攻击、易伤配合、消耗燃料与收益、稳定格挡或过牌能量。拿到一张力量牌不代表已经成型；拿到一个格挡组件也不代表应把所有奖励转成防守。

看到三张奖励牌时，先按当前完整牌组给每张牌找职责，再看它实际补上什么、和现有牌/遗物如何联动，以及它会不会让抽牌变稀。把“跳过”作为基准：只有某张牌明确补当前缺口、完善已经出现的引擎，或针对近期首领/精英的机制，才值得扩充牌组；三张都只是能用、重复已解决的职责，或依赖尚不存在的组件时就跳过。牌组达到20张后把扩充门槛调高：普通伤害、重复定位、尚无支持的条件牌通常不如跳过；只有明显强牌、真实缺口或近期威胁解法才继续加牌。20张是本项目的选牌倾向，不是游戏规则。不要为了避免空手离开奖励而抓中等牌。单候选直接选；卡牌强度榜只做先验，不能代替当前牌组评价。

强化优先级也随牌组和近期节点变化：优先会跨过近期伤害/存活断点、降低关键费用或让核心牌更稳定的升级；其后才看泛用数值。用游戏当前升级预览比较前后效果，不把其他版本的卡牌数值搬进来。

## KEV 与 Luna 的上下文

- **KEV 仅负责战斗战术。** 输入当前手牌、牌堆可见信息、能量、HP/格挡、敌人状态/意图、遗物/药水，以及可执行的完整本回合线路。KEV 的选择类别代表线路，不代表自由文本；类别的第一步仍必须映射到当前合法动作。KEV 不读取 Luna Skill、`luna_context`、路线规划或卡牌奖励偏好。
- **Luna 负责策略选择。** Luna 在奖励、商店、事件、休息和整图规划等真实策略节点读取 Ironclad Skill、当前完整牌组和有界 `luna_context`。路线确认后，按既定路线前进由控制器确定性执行，不重复问 Luna。
- **动态事实与假设分开。** 游戏接受的牌/遗物是事实；Luna 的流派判断是可被后续选择修正的假设。KEV 每次只按最新实时战斗状态行动。不要为了更新上下文多发模型请求。

## 估值边界与复盘

当前本地线路搜索是可解释的**有限估算器**，不是完整战斗模拟器。抽牌、药水、多段/AoE/X 费、混合效果、任意遗物联动、未解析意图和未知牌效都可能让线路不完整。对不确定效果应保留给模型比较并在日志中标记，不能用“没看到收益”伪装成“确定没收益”。动作 POST 超时后只重读游戏状态，不重复提交。

每局复盘检查：

- 是否选了只削敌人格挡、没有同回合 HP 后续的攻击；
- 是否为零收益力量/易伤或无当前防守价值的格挡浪费能量；
- 是否漏算已有格挡、多名敌人或击杀后仍在的攻击；
- 是否漏记卡牌自损、过量伤害、手里可支付的后续攻击；
- 战斗结束时失去多少 HP、何时使用战后回血、该局的牌组职能是否缺失。
